# Twintable

I am building a website where it is a search bar. Where you search for a restaurant and a city and it uses Claude to give you the restaurants in the inputted city similar to the inputted restaurant. There should be star ratings determined by claude for food similarity, ambiance similarity, and other relevant factors. and also have price from $ through $$$$.
